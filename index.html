FEATURED PROJECTCLOUD PROJECT · AWS

AWS Static Website Hosting
with S3 & CloudFront

I deployed a static website using Amazon S3 and Amazon CloudFront, creating a cloud-based hosting architecture that delivers the website over HTTPS.

User→CloudFront→S3

CloudFront acts as the public entry point while the S3 bucket stores the website files.

AWS services

  • Amazon S3
  • Amazon CloudFront
  • S3 Bucket Policy
  • CloudFront access controls

What I implemented

  • Created and configured an S3 bucket
  • Uploaded static website files
  • Configured static website hosting
  • Created an S3 bucket policy
  • Created a CloudFront distribution
  • Connected CloudFront to the S3 origin
  • Configured CloudFront access to the S3 bucket
  • Enabled HTTPS delivery and tested the deployed website
↗

What I learned

This project helped me understand how AWS services work together rather than learning each service in isolation. I gained practical experience with object storage, CDN delivery, HTTPS, access policies, cloud origins, and the relationship between CloudFront and S3.
